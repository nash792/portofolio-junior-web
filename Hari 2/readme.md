# Website Sederhana

Contoh website statis sederhana menggunakan HTML.

## Daftar file
- `index.html` — halaman utama
- `tentang.html` — informasi tentang website
- `kontak.html` — informasi kontak
- `form.html` — contoh formulir
- `tabel.html` — contoh tabel data

## Cara menjalankan
1. Ekstrak semua file ke dalam satu folder.
2. Buka `index.html` menggunakan browser.
3. Gunakan menu navigasi untuk membuka halaman lainnya.

Tidak membutuhkan server atau instalasi tambahan.
