
# Hello World - Node.js

## Deskripsi
Hello World adalah proyek sederhana menggunakan Node.js
yang bertujuan untuk menampilkan tulisan "hello world"
pada console.

## Teknologi
- Node.js
- JavaScript
- NPM
- Git

## Struktur Proyek
```text
hello-world/
├── src/
│   └── index.js
├── package.json
├── package-lock.json
└── README.md
```

## Cara Menjalankan Program

Pastikan Node.js sudah terinstal.

### Cara 1: Menggunakan Node.js
```bash
node src/index.js
```

### Cara 2: Menggunakan NPM
```bash
npm start
```

## Output
```text
hello world
```
